# Annotation Guidelines

This directory contains the annotation guidelines and tool used for human validation of NLI-gated content preservation (Section 4.4, Appendix V).

## Contents
- `guidelines.md` — Annotation instructions given to annotators
- `annotation_tool.html` — Browser-based annotation interface (open in any modern browser)

## Task
Two independent annotators evaluated 100 NLI-scored pairs (50 formality, 50 verbosity) for content preservation. See the paper Appendix for agreement statistics (Gwet's AC₁ = 0.958, gate pass precision = 98.6%).
